    Cheatsheet

    Workflow

    1. Equations (enter): one card per equation, in LaTeX.
    2. Variables (enter): value, unit, size, code name, description.
    3. Plan (get): connections and order of solution.
    4. Flowchart (get): .svg, .png, TikZ .tex, Mermaid.
    5. Code (get): Python, MATLAB, Fortran.
    6. Report (get): LaTeX write-up with references.

    Write it like this · the type follows

    Plain math or LaTeX. Plain: * / ^ ( ), sqrt(x), exp, ln, log10, sin…; rho → , c_p → , T_inf → , Re → , dT/dt → , d2x/dt2 → . Sums, integrals and vectors need LaTeX.

    N_steps = 100
    Convergence loop
    tol = 1e-6, max_iter = 500

    Integral
    bounds from , n = 100 intervals
    Implicit
    method = newton, tol = 1e-10, max_iter = 50, and guess, min, max to pick the branch (numbers, variables or LaTeX: min = b). The root plot on the card shows every root: click one to use it.
    ODE
    t = 0..t_end, steps = 100, method = rk4 (or euler), save = 10 writes a CSV every 10 steps. The state's Value is its initial value. A second-order ODE has two states, and : give both Values. On its right side, means ; elsewhere write .

    Switches · Applies when

    Give two or more equations the same output and a condition each; the first that holds is used.

    Applies when R_e < 2300
    Applies when otherwise

    Without an otherwise case the Value is kept.

    Variables

    Roles
    input state intermediate output, from how equations use them.
    Value
    inputs, initial values and guesses: 1.5 · vector 1, 2, 3 · matrix 1, 2; 3, 4 · identity I
    Unit
    W/(m·K), kg m^-3, m/s^2, kPa, °C; 1 or - = dimensionless; empty = not given
    Size
    empty = scalar, 3 = vector, 3 x 3 or N x 2 = matrix
    Code name
    the name in exported code (empty = automatic). Fortran ignores case: T and t clash.
    To check
    the filter that lists missing units, sizes and descriptions and bad code names.
